# ✍️ Blogr Landing Page
This project is a modern and responsive landing page for Blogr, a fictional, next-generation publishing platform. It's designed to be a visually engaging entry point for a service that helps users build their online brand and grow their audience.

![Screenshot of the page](/images/screenshot-1.png)

![Screenshot of the page](/images/screenshot-2.png)

## ✨ Features
- Responsive Design: Adapts seamlessly to different screen sizes, from desktops to tablets and mobile devices.

- Interactive Elements: Includes a functional mobile navigation menu with JavaScript-powered interactions.

- Clean UI: Presents information in a clear, modern, and professional layout.

## 🚀 Live Demo
Try the live version here: https://styn1s.github.io/Blogr/

## 🛠️ Technologies Used
- HTML5: For structuring the page content.

- CSS3: For styling, layout, and animations.

- JavaScript: For adding interactivity (e.g., mobile menu toggle).
